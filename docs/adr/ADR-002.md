# ADR-002: bounded tabular exploration

Status: accepted for V1.

Context: the product question is a first review of one CSV, not recurring monitoring or warehouse validation.

Decision: keep the small Streamlit app and flat Python modules, separate ingestion and orchestration where failure boundaries justify it, and enforce byte/row/column/cell/frame guards. Retain pandas/NumPy in-memory analysis. Do not add storage, authentication, queues, distributed execution or Docker solely for appearances.

Consequences: easy offline use and a simple deployable repository. Hosted mode still transfers uploads to a server. V1 does not handle ten-million-row workloads or offer tenant isolation/concurrency guarantees. Database adapters, historical baselines and monitoring require new requirements and measurements.
