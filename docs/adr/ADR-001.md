# ADR-001: deterministic findings, optional explanations

Status: accepted for V1.

Context: reproducible quality findings must work offline. Model output is variable and can invent plausible facts.

Decision: Python computes statistics, issues, severity, ordering and score. The provider sees an aggregate allowlist with anonymous columns and returns a bounded Pydantic explanation schema. Identity/order and numeric-claim checks reject inappropriate responses. Authored guidance covers every finding and provider failure.

Consequences: reliable core and independently testable boundaries; limited model flexibility. Schema/lexical checks cannot establish the truth of prose, so suggestions remain labeled and conditional. No LLM-dependent pass/fail exists.
