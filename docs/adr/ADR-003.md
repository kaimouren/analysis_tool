# ADR-003: an inspectable heuristic score

Status: accepted; default score policy 1.0 retained, profile schema 1.2.

Context: an aggregate indicator aids triage but can falsely imply calibrated quality or hide severe local issues.

Decision: preserve bounded category penalties with explicit denominators, caps and six-decimal penalty rounding; round final score to two decimals. Empty data scores zero. Severity drives review status independently. Keep new whitespace/casing checks advisory and unscored. Centralize thresholds and serialize effective overrides with the profile.

Consequences: reproducible arithmetic and stable planted-sample regression without invented scientific justification. Overlapping checks are not independent; broad schemas dilute localized defects and the IQR scoring gate introduces a discontinuity. Scores are not comparable universal quality probabilities, and overrides must be compared using the recorded effective policy rather than a version label alone. Calibration needs labeled real-world outcomes; none is claimed.
